# Halden Fitness Club

A responsive one-page website for a fictional boutique fitness club. This is a concept project made for my portfolio, not a real client's site.

**Live site:** https://zerocreator-eng.github.io/halden-fitness-club/

## Features
- Responsive layout that works on desktop and mobile
- Sections for classes, trainers, membership plans, weekly schedule, and contact
- Schedule table with a day filter
- Contact form with validation and a confirmation message (demo only, nothing is sent)
- Rotating hero statements, with reduced-motion support
- Semantic HTML, keyboard focus styles, and alt text on images

## Built with
- HTML
- CSS (custom properties, Grid, Flexbox)
- JavaScript (no frameworks)

## Run it locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Notes
- All names, prices, and the address are made up.
- The images are AI-generated.
